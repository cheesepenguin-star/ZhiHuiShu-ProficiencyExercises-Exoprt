# 智慧树掌握度题目导出器

当前版本：1.0.0

这个脚本服务于共享课课程的“知识点掌握度”板块。暂时不知道智慧树的其他类型课程能否使用，我没有尝试过




## 安装

1. 在 Chrome 或 Edge 安装并启用 Tampermonkey（篡改猴）。
2. 打开 Tampermonkey 管理面板。
3. 新安装时选择“添加新脚本”；更新时打开旧脚本的编辑页面。
4. 把 “智慧树掌握度题目导出器”的内容 全部复制进去并保存。
5. 回到智慧树课程的“掌握度”页面，刷新一下。




## 操作流程

1. 打开课程的“掌握度”页面，等待知识点卡片加载完成。
2. 点击右下角面板中的“识别知识点”。
3. 脚本会滚动页面并核对知识点数量。识别完成后只显示范围输入框，此时不会立即开始采集。
4. 输入起始和结束序号。序号从 1 开始，包含首尾，例如 `20 至 40` 表示采集第 20—40 个知识点，共 21 个。
5. 点击“开始所选区间”。脚本会依次进入知识点练习，读取每组 5 道题，再返回掌握度页继续。
6. 区间完成后，点击“导出给 AI”。生成的 `.md` 文件可直接发送给 DeepSeek、豆包等 AI。

每次开始一个新区间时，脚本都会清空上一轮尚存在于浏览器中的题目、完成标记和错误提示，避免不同轮次互相混入。请先导出需要保留的成果。



## 暂停、继续和部分导出

- 运行中点击“暂停”，采集会停止。
- 只要本轮至少成功读取了 1 道题，“导出给 AI（当前成果）”就可以被启用，不要求整个区间全部完成。
- 暂停后如果还没有导出，可以回到掌握度页点击“继续所选区间”，已采集内容会保留。
- 点击导出后，无论所选区间是否完成，本次采集都会正式结束，不能再从原进度继续。下一轮必须重新点击“识别知识点”并重新选择区间。
- 已导出的成果仍可点击“再次导出当前成果”重新下载，但这不会恢复采集任务。
- 如果区间已经走完但存在缺题，脚本会停止并标记为“部分”，仍允许导出实际已采集的题目。

运行期间尽量不要手动切换题目。若暂停发生在知识点练习页，请先返回掌握度页再继续；也可以直接导出当前成果。




## 右下角没有出现面板

如果脚本已经保存并启用，但智慧树页面右下角完全没有面板，请优先检查 Edge 是否允许 Tampermonkey 执行用户脚本。Tampermonkey 5.3 及以上版本在 Chromium 内核浏览器中需要额外授权；仅仅安装并启用扩展，仍可能无法运行任何用户脚本。

### 第一步：开启 Edge 的“开发人员模式”

1. 在 Edge 新标签页的地址栏输入 `edge://extensions`，然后按回车。
2. 找到页面右上角的“开发人员模式”开关并开启。
3. 这里指的是扩展管理页中的开关，不是按 `F12` 打开的网页开发者工具。
4. 在同一页面找到 Tampermonkey，确认卡片右下角的启用开关已经打开。
5. 点击 Tampermonkey 卡片中的“详细信息”。如果页面中还能看到“允许用户脚本”或 `Allow User Scripts`，也可以改为开启这个选项。官方要求“允许用户脚本”和“开发人员模式”至少开启一个，并不要求两个同时开启；不同 Edge 和 Tampermonkey 版本显示的选项可能不同。Edge 用户按本说明保持“开发人员模式”开启即可。

Tampermonkey 官方说明：在较新的 Chromium 内核浏览器中，需要开启“允许用户脚本”或“开发人员模式”中的至少一个，Tampermonkey 才能使用浏览器的 `userScripts` 能力。对于 Edge，遇到脚本完全不运行时，应首先检查“开发人员模式”。这一授权与后文的“网站访问权限”是两层不同的设置：前者允许 Tampermonkey 执行用户脚本，后者决定它能否在智慧树网站运行。

如果“开发人员模式”开关不存在、呈灰色，或者页面显示“由你的组织管理”，通常说明学校或单位策略禁用了此功能。不要尝试绕过设备管理策略；可以改用个人设备，或联系设备管理员确认。

### 第二步：确认 Tampermonkey 和脚本均已启用

1. 在 `edge://extensions` 中确认 Tampermonkey 本身处于启用状态。
2. 点击浏览器右上角的 Tampermonkey 图标，进入“管理面板”。
3. 在“已安装脚本”中找到“智慧树掌握度题目导出器”，确认脚本左侧或右侧的启用开关已经打开。
4. 点击脚本名称进入编辑页面，确认编辑器中确实存在完整代码，然后按 `Ctrl+S` 保存。
5. 仅仅在资源管理器中打开 `.user.js` 文件，或者只把文件下载到电脑中，并不等于已经安装进 Tampermonkey。

### 第三步：允许 Tampermonkey 访问智慧树网站

1. 打开 `edge://extensions`，在 Tampermonkey 卡片中点击“详细信息”。
2. 找到“网站访问权限”“站点访问”或类似选项。
3. 可以选择“在特定网站上”，并允许下面的地址：

   - `https://studywisdomh5.zhihuishu.com/*`
   - `https://wisdom-mooc.zhihuishu.com/*`

4. 如果当前 Edge 版本不方便逐项添加，也可以选择“在所有网站上”。如果选择“单击扩展时”，则每次重新打开或刷新智慧树页面后，都可能需要再次点击 Tampermonkey 图标授权当前页面。
5. 如果浏览器只接受域名级规则，也可以允许 `https://*.zhihuishu.com/*`，但它授予的范围更大。

### 第四步：确认打开的是正确页面

脚本面板只会在课程的“掌握度”页面，以及由该采集任务自动进入的知识点练习页面中显示。请检查：

1. 当前已经登录智慧树，没有停留在统一登录或验证码页面。
2. 当前页面是课程的“知识点掌握度”页面，不是课程首页、作业列表或独立考试页面。

### 第五步：保存后刷新

1. 保存脚本和权限设置后，回到掌握度页面。
2. 按 `Ctrl+Shift+R` 强制刷新；普通刷新有时仍会沿用旧页面缓存。
3. 页面加载完成后等待几秒，再查看右下角是否出现“智慧树掌握度题目导出器”。
4. 点击浏览器右上角的 Tampermonkey 图标：

   - 如果能看到“智慧树掌握度题目导出器”，说明脚本已匹配当前网址；再检查它是否被关闭。
   - 如果显示当前页面没有脚本运行，通常是页面地址不正确、脚本未保存，或网站访问权限没有开放。

### 第六步：仍未出现时收集排查信息

可以依次尝试：

1. 完全关闭并重新打开 Edge，再进入掌握度页面。
2. 临时关闭可能拦截页面脚本的其他扩展，然后再次强制刷新。
3. 按 `F12` 打开网页开发者工具，切换到“控制台（Console）”，搜索 `[智慧树题目导出]`，查看是否有红色错误。
4. 截图以下内容：

   - `edge://extensions` 页面右上角“开发人员模式”的状态；
   - Tampermonkey 的扩展详情和网站访问权限；
   - Tampermonkey 弹出菜单中当前页面的脚本状态；
   - 智慧树页面地址栏和页面主体。

官方参考：

- [Tampermonkey：执行用户脚本所需权限](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)

## 重要限制

- “全部”只指当前账号通过页面能够打开并实际下发的题目，不代表服务器中未向你展示的隐藏题库。
- 页面如果随机出题，每次采集只代表当次页面实际展示的内容。





## 导出文件的结构

导出文件会保留：

- 页面上的分组大标题；
- 每个知识点的全局序号和完整标题；
- 每道题在该知识点中的题号；
- 题型、题干、A/B/C/D 等全部选项；
- 公式文本与页面图片链接；
- 所选知识点范围、实际题数、理论题数、完整或部分状态；
- 部分采集时尚未读取到的定位编号。

定位编号采用“知识点全局序号-组内题号”。例如 `027-4` 表示课程中第 27 个知识点的第 4 题。即使只采集第 20—40 个知识点，编号仍保留为 `020-*` 至 `040-*`，不会重新从 1 编号。

AI 题单本身仍包含完整题干和全部选项，供模型判断；但要求模型作答时只返回“定位编号＋选项字母”，无需重复选项内容，例如：

```text
## 知识点 027/148｜知识点完整标题
027-4. B
027-5. AC
```

题单还会明确要求 AI 只回答文件中实际列出的题目，不补写未采集题号。AI 生成内容只是候选答案，作为标准答案使用前仍应人工复核。

## 完整性与题数

掌握度练习按每个知识点 5 道题检查。

脚本不会按题干或平台题目 ID 跨知识点合并。同一道题即使出现在多个知识点中，也会按各自题位分别保留。它会检查：

- 页面显示的知识点总数是否与实际识别数一致；
- 每个知识点的答题卡是否完整显示 `1、2、3、4、5`；
- 切换后题面是否稳定且题号匹配；
- 选择题是否至少读取到两个可用选项；
- 所选区间中哪些题位缺失。
